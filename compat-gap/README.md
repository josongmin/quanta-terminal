# `compat-gap/` — Compat Mismatch Reports

This directory is the intake queue for compat-matrix failures produced by
the golden-replay harness (`crates/quanta-vt/tests/compat_harness.rs`) and
the scripted interactive runner
(`tests/integration/tests/compat_scripted.rs`).

Whenever a harness run produces a mismatch between `expected_*.json` and
what the engine actually produced, a file named
`<program>_<timestamp>.report` is emitted here. The report schema is
versioned and pinned in `TEMPLATE.md` (schema_version = 1 per
`docs/plans/0001-custom-vt-engine-xterm-removal/epic-G-compat-matrix.md`
§4.5).

## Directory contract

| Path | Tracked in git? | Purpose |
|------|-----------------|---------|
| `README.md` | yes | This file. |
| `TEMPLATE.md` | yes | Canonical `<program>_<timestamp>.report` shape. |
| `.gitignore` | yes | Ignores generated `*.report` files. |
| `resolved/` | yes (directory kept via `.gitkeep`) | Archive of fixed/deferred gaps. |
| `<program>_<timestamp>.report` | **no** | Auto-generated by a failing harness run. |

Unresolved `*.report` files at repo root (outside `resolved/`) are the
signal that a compat gap exists. CI check `compat-gap-empty-check`
enforces "no unresolved reports at EPIC-H kickoff commit".

## Triage workflow

1. Read the `diffs` array in the report.
2. Classify the divergence:
   - **Engine bug** — file an issue against `quanta-vt`; reference the
     report filename. Fix lands with a reviewable test case added to
     `crates/quanta-vt/tests/`. Once green, move the report to
     `resolved/<program>_<ts>_resolved.md` with a short resolution note.
   - **Fixture staleness** — a legitimate program update changed the
     output since the golden was captured. Re-record via
     `scripts/record-compat-stream.sh`, bump `VERSIONS.md`, move the
     report to `resolved/<program>_<ts>_rerecord.md`.
   - **Recording-env drift** — host terminal differs from the fixed
     capture env (§4.1 of the plan). Reproduce under the canonical env
     before deciding; if the capture env needs updating, document it
     in `scripts/record-compat-stream.sh` and re-record.
   - **Deferred** — legitimate gap that won't be fixed this pass. Move
     to `resolved/<program>_<ts>_deferred.md` with a rationale and a
     tracking issue link. RFC §19 removal gate stays blocked until the
     deferred tracking is resolved.

## Report anatomy

See `TEMPLATE.md` for the full shape. Key fields:

- `schema_version` — pin for the report format. Bumping requires a
  harness update.
- `program` — matches the fixture directory name under
  `crates/quanta-vt/tests/compat/<program>/`.
- `harness` — `"replay"` (golden-stream) or `"scripted"` (interactive).
- `diffs[]` — first-N divergent items (grid cells, cursor, modes).
- `versions_md_excerpt` — snapshot of `VERSIONS.md` at the time of the
  failing run, for post-mortem provenance.
